    System report

    Windows already keeps a crash history, a battery report and a system summary. Save them with the steps below and PC Check reads them right here in your browser. The files never leave your device.

    1. 1Crash history

      1. Press Win + R, type perfmon /rel and press Enter.
      2. At the bottom of Reliability Monitor, click “Save reliability history…” and save the .xml file.

    2. 2Battery (optional, laptops)

      1. Press Win + R, paste this command and press Enter: powercfg /batteryreport /output "%USERPROFILE%\Desktop\battery-report.html"
      2. It creates a battery report file on your Desktop; it changes nothing.

    3. 3System info (optional)

      1. Press Win + R, type msinfo32 and press Enter.
      2. Choose File > Export and save the .txt file. It can be large; only the first part is read.

    Analyze runs on this device. Nothing is uploaded, so nothing is added to the outbound log.

    1. 1System

      Shows the kernel version and which Linux you run.

      uname -a; cat /etc/os-release

      It only reads; it changes nothing.

    2. 2Errors since this start-up

      Lists error messages logged since the computer was switched on. LC_ALL=C makes this one command print in English.

      LC_ALL=C journalctl -b -p 3 -o short --no-pager

      It only reads; it changes nothing.

      If it says you are not seeing messages from the system, your account can only see part of the log; the results will say so.

    3. 3Previous start-ups

      Lists the last five start-ups and the errors from the one before this, to spot a crash or freeze.

      LC_ALL=C journalctl --list-boots --no-pager | tail -5; LC_ALL=C journalctl -b -1 -p 3 -o short --no-pager

      It only reads; it changes nothing.

    4. 4Battery (laptops, optional)

      Shows how much charge the battery holds compared with new. On a desktop it prints nothing; leave the box empty.

      upower -i $(upower -e | grep BAT)

      It only reads; it changes nothing.

    5. 5Disks

      Shows how full each disk is.

      LC_ALL=C df -h; LC_ALL=C lsblk -o NAME,SIZE,TYPE,MOUNTPOINT

      It only reads; it changes nothing.

    Analyze runs on this device. Nothing you paste is uploaded, so nothing is added to the outbound log.

    How it works

    Password: your browser turns the password into a code (SHA-1 hash) and sends only the first 5 characters. Pwned Passwords returns hundreds of codes that start the same way, and the comparison happens here. Not even the service knows which password you checked.

    DNS: your browser looks up 20 test addresses that exist only for you. The bash.ws service records which DNS servers made those lookups and compares them with your connection’s network.

    Connection: Cloudflare reports how your browser connected to it, including the TLS version and whether the site name was hidden (ECH).

    Browser: the version is read right here and compared with the latest version published by Google and Mozilla.

    This page uses no cookies, no analytics and no third-party scripts.
