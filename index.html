    How it works

    Password: your browser turns the password into a code (SHA-1 hash) and sends only the first 5 characters. Pwned Passwords returns hundreds of codes that start the same way, and the comparison happens here. Not even the service knows which password you checked.

    DNS: your browser looks up 20 test addresses that exist only for you. The bash.ws service records which DNS servers made those lookups and compares them with your connection’s network.

    Connection: Cloudflare reports how your browser connected to it, including the TLS version and whether the site name was hidden (ECH).

    Browser: the version is read right here and compared with the latest version published by Google and Mozilla.

    This page uses no cookies, no analytics and no third-party scripts.

    Services used: Pwned Passwords, Cloudflare and bash.ws.
